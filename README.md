# nextpvr-ccextractor
Custom build of [NextPVR](https://nextpvr.com/) docker container that includes
- [ccextractor](https://github.com/CCExtractor/ccextractor)
- [comskip](https://github.com/erikkaashoek/Comskip)
- [ffmpeg 8.1 nightly](https://github.com/BtbN/FFmpeg-Builds) in `/app/ffmpeg8`
- some other misc tools.
